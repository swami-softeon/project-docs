Allocation

Context: order_header.ord_sub_status 10 = waiting for allocation; 20 = all lines fully allocated. order_detail.alloc_qty is updated as soon as a line is allocated, so a status-10 order can hold units on some lines while other lines are short. Those units can block other orders. Allocation runs every 10 minutes. Both queries are read-only, assume no free stock, and need the company set in the params CTE.

1. Orders to de-allocate and hold, so other orders can move on

Returns the orders (status 10, holding units) whose allocation can be released and then put on hold, so that waiting orders can fully allocate on the next run.

-- Orders to de-allocate + hold so that other waiting orders (ord_sub_status=10) can fully allocate.
-- Read-only. Change the company in params. Assumption: no free stock (allocation runs every 10 min).
WITH RECURSIVE
params AS (SELECT '<COMPANY_NO>'::text AS company_no),
lines AS (
  SELECT d.ord_no, d.sku,
         SUM(d.ord_qty)::numeric                 AS ord_qty,
         SUM(COALESCE(d.alloc_qty,0))::numeric   AS alloc_qty
  FROM order_detail d
  JOIN order_header h ON h.company_no = d.company_no AND h.ord_no = d.ord_no
  JOIN params p ON p.company_no = h.company_no
  WHERE h.ord_sub_status = 10
  GROUP BY d.ord_no, d.sku
),
-- pool = everything currently held by waiting orders (what could be redistributed)
pool0 AS (SELECT jsonb_object_agg(sku, held) AS pool FROM (SELECT sku, SUM(alloc_qty) held FROM lines GROUP BY sku) x),
-- smallest orders first
ranked AS (
  SELECT ord_no, ROW_NUMBER() OVER (ORDER BY SUM(ord_qty), ord_no) rn
  FROM lines GROUP BY ord_no
),
n AS (SELECT MAX(rn) mx FROM ranked),
-- greedy: walk orders smallest-first, take an order if the pool covers ALL its lines, then deplete pool
walk(rn, pool, picked) AS (
  SELECT 0, (SELECT pool FROM pool0), NULL::text
  UNION ALL
  SELECT w.rn+1,
    CASE WHEN ok.fits THEN
      (SELECT w.pool || COALESCE(jsonb_object_agg(l.sku, (w.pool->>l.sku)::numeric - l.ord_qty), '{}'::jsonb)
         FROM lines l WHERE l.ord_no = r.ord_no)
    ELSE w.pool END,
    CASE WHEN ok.fits THEN r.ord_no END
  FROM walk w
  JOIN ranked r ON r.rn = w.rn+1
  CROSS JOIN LATERAL (
    SELECT NOT EXISTS (SELECT 1 FROM lines l WHERE l.ord_no=r.ord_no
                       AND COALESCE((w.pool->>l.sku)::numeric,0) < l.ord_qty) AS fits
  ) ok
),
will_complete AS (SELECT picked AS ord_no FROM walk WHERE picked IS NOT NULL),
-- extra units those orders still need, per SKU
need AS (
  SELECT l.sku, SUM(l.ord_qty - l.alloc_qty) need_qty
  FROM lines l JOIN will_complete w USING (ord_no)
  GROUP BY l.sku HAVING SUM(l.ord_qty - l.alloc_qty) > 0
),
-- candidate holders: not completing, holding units of a needed SKU; biggest holders first per SKU
holders AS (
  SELECT l.ord_no, l.sku, l.alloc_qty, n.need_qty,
         COALESCE(SUM(l.alloc_qty) OVER (PARTITION BY l.sku ORDER BY l.alloc_qty DESC, l.ord_no
                  ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING),0) AS cum_before
  FROM lines l
  JOIN need n ON n.sku = l.sku
  WHERE l.alloc_qty > 0 AND l.ord_no NOT IN (SELECT ord_no FROM will_complete)
),
release AS (SELECT DISTINCT ord_no FROM holders WHERE cum_before < need_qty)
SELECT r.ord_no AS order_to_release_and_hold,
       (SELECT SUM(alloc_qty) FROM lines l WHERE l.ord_no = r.ord_no) AS units_released
FROM release r
ORDER BY 1;

2. Count of orders that will be released

Same logic, summarised: orders to release and hold, units freed, and orders expected to complete.

-- Orders to de-allocate + hold so that other waiting orders (ord_sub_status=10) can fully allocate.
-- Read-only. Change the company in params. Assumption: no free stock (allocation runs every 10 min).
WITH RECURSIVE
params AS (SELECT '<COMPANY_NO>'::text AS company_no),
lines AS (
  SELECT d.ord_no, d.sku,
         SUM(d.ord_qty)::numeric                 AS ord_qty,
         SUM(COALESCE(d.alloc_qty,0))::numeric   AS alloc_qty
  FROM order_detail d
  JOIN order_header h ON h.company_no = d.company_no AND h.ord_no = d.ord_no
  JOIN params p ON p.company_no = h.company_no
  WHERE h.ord_sub_status = 10

       (SELECT SUM(l.alloc_qty) FROM lines l WHERE l.ord_no IN (SELECT ord_no FROM release)) AS units_freed,
       (SELECT COUNT(*) FROM will_complete)  AS orders_that_will_complete;
